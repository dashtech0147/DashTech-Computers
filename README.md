# DashTech Computers

## ICT & Consultancy Services

DashTech Computers is an ICT and consultancy service provider focused on
helping businesses establish and maintain a professional digital presence.

Our services include website development, website hosting, domain
registration, business email solutions, branding, software installation,
computer maintenance, and digital transformation services.

---

## About This Project

This repository contains the source code and related resources used for
the DashTech Computers website and its associated web applications.

The project is designed to provide customers with information about
DashTech Computers' services, portfolio, pricing, website hosting
options, booking services, and contact information.

---

Installation

Requirements

Before deploying the project, ensure the hosting environment supports:

PHP
MySQL
SMTP
cPanel or an equivalent hosting control panel
SSL/HTTPS
Required PHP extensions

⸻

Configuration

Before running the application in a production environment:

Configure the database connection.
Configure the SMTP mail server.
Configure Google reCAPTCHA credentials.
Configure required API credentials.
Configure the website domain.
Enable HTTPS/SSL.
Configure the required database tables.
Verify file and directory permissions.
Test the booking and email systems.

Security

Never commit passwords, API secret keys, database credentials,
SMTP passwords, private keys, or other sensitive information to GitHub.

Production credentials should be stored securely outside the public
repository.

⸻

Database

The application may use MySQL for storing application data such as
website booking information.

Database credentials must never be committed to the repository.

Use a secure configuration or environment-based approach for production
credentials.

⸻

Email

The website may use SMTP and PHPMailer for sending transactional emails.

SMTP credentials must remain private and must never be committed to the
repository.

⸻

Google reCAPTCHA

The booking system may use Google reCAPTCHA to help protect forms from
automated submissions and abuse.

The following credentials must remain private:

Secret key
API credentials
Other private authentication credentials

Public site keys may be used where appropriate.
